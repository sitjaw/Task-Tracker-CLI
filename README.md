# Task-Tracker-CLI
this project is Task Tracker CLI

I created this project to practice programming logic and gain experience. However, this code isn't 100% mine; some of it uses AI because there's some logic I don't yet understand.
The way this program works is when I request "add" in the terminal with a description like "Buy groceries," the program will create the file first if it doesn't already exist, then add the task properties, such as:
id: A unique identifier for the task
description: A short description of the task
status: The status of the task (todo, in-progress, done)
createdAt: The date and time when the task was created
updatedAt: The date and time when the task was last updated

For more information, see roadmap.sh
https://roadmap.sh/projects/task-tracker
